# Task handoff template

Use for an unfinished task/session transfer, not as a mandatory permanent document.
Store only useful technical state; exclude credentials and private data.

## Goal and acceptance

Requested behavior, confirmed constraints and what counts as complete.

## Current state

Branch/commit if known, relevant working-tree changes, implemented behavior and actual
files touched. Identify unrelated user changes that must remain intact.

## Evidence

Commands/scenarios, environment and Passed / Failed / Blocked / Not run results.
Separate observations from hypotheses and include minimal relevant artifact references.

## Remaining work

Concrete next action, unresolved issue/decision and useful source paths. Explain whether
the blocker requires environment access, a product decision or implementation work.

## Decisions to preserve

Link accepted decisions and relevant instructions rather than pasting every document.
Do not tell the next agent to disregard existing rules or represent assumptions as facts.
