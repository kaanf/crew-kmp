## Report a vulnerability

Send a private email and identify it as a security report in the subject. Include affected
versions/platforms, reproducible steps using test accounts, expected/observed behavior
and a concise impact explanation. Omit credentials and unnecessary personal data.
Do not submit exploit details, active tokens or another user's records in public issues.

GitHub private vulnerability reporting has not been verified as enabled for this repository.
Do not assume that creating this file enables it or any scanning service.
